W2C — Image Suggestion
Generate prompt → Copy → paste to ChatGPT → paste JSON response → Save
Reads the selected HTML source, finds every H2 heading and builds a ChatGPT prompt asking it to suggest suitable images for each heading.
ChatGPT returns a JSON array of image suggestions. Clear & Paste brings it from your clipboard. Save to Sheet writes the JSON to column FK.
Reads the HTML source selected in Step 1 and the JSON from column FK. Injects a comment placeholder after each H2 showing where each image will go. Saves the result to column FL.
Writes one row per image suggestion into the Image Library sheet with Post ID, H2 heading, slug, alt, caption and AI prompt. This is your working list for sourcing and generating images.
Opens a modal showing the column FL content — raw HTML code tab and a WYSIWYG preview tab — so you can see the article with the comment placeholders in place.
Once you have added image URLs to column H of the Image Library, this builds a ChatGPT prompt to write the complete figure HTML for each image — with alt text, diagnostic captions, and linked captions where column K has a URL. Save Figure HTML writes the result to column L of the Image Library.
Reads Image Library rows where Status is Ready, takes the figure HTML from column L, and replaces the comment placeholders in column FL with real figure tags. Updates Status to Injected.
Manual fallback only — use this if you have edited the FL HTML yourself outside the pipeline. Clear & Paste brings your edited version in, Save to Sheet overwrites column FL.
